# speakTTS
This function makes a speaking voice. To use this function, use the following code:

`mpaxfw.speakTTS('[text]', [rate], [pitch], [volume]);`

For example, if you want to make a speaking voice with the text of `Hello mpax235 Framework!` and a rate, pitch, and volume of `1`, it would be:

`mpaxfw.speakTTS('Hello mpax235 Framework!', 1, 1, 1);`
